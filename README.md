# 문명: 멸망 후 50년 뒤 2076년 (팬 게임)

유튜브 채널 「문명」의 영상 **「문명2 EP.1」시작**, **「문명2 EP.2」일상** 을 바탕으로 만든 비공식 3D 팬 게임입니다.

▶ **플레이:** https://9allproject9-creator.github.io/civilization-2076/

## 이야기 (EP.1 「시작」)
세상이 멸망한 지 50년, 2076년. 하천 둑길 옆 작은 콘크리트 창고에서 눈을 뜬 주인공은
겨울을 나기 위해 하루를 시작합니다.

1. 침낭에서 일어나 난로 불씨에 장작을 얹고, 작은 스텐 냄비로 물을 끓여 마신다
2. 문가에 흩어진 재첩 껍데기와 작은 발자국 — 쥐의 흔적을 발견한다
3. 리어카 방수포를 들춰 종자 팩을 확인하고, 섬진강 휴게소 주방에서 스텐 밀폐용기를 찾아온다
4. 빈 리어카를 끌고 낡은 마을의 낚시가게에서 합사줄과 낚싯바늘을 구한다
5. 부들·돼지감자·냉이 자리에 나뭇가지를 꽂아 표시하고, 쓰러진 고목에서 하늘소 유충을 얻는다
6. 섬진강교 난간에 낚싯줄 8개를 내려 묶고 집으로 돌아온다 — 그리고 불청객들이 나타난다

## 이야기 (EP.2 「일상」)
쥐가 벽 틈으로 사라진 그날 밤.

1. 스텐 용기를 열어 종자와 식량을 확인하고, 병균이 들어오지 못하게 구멍을 막기로 한다
2. 참나무숲에서 낙엽을 들추다 도토리를 발견하고, 돌멩이와 진흙을 챙긴다
3. 벽 틈새를 돌과 진흙으로 막고, 들통에 냇물을 받아 도토리를 불린다
4. 돼지감자를 난로 안쪽에 넣어 익히고, 상판에서 냉이국을 끓여 식사한다
5. 깜빡 잠든 사이 옛 기억이 스친다 — 일어나 냇가에서 설거지를 하고 페트병 통발을 설치한다

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 |
| 달리기 | Shift | 달리기 버튼 |
| 시점 | 화면 클릭 후 마우스 (Esc 해제), 휠 줌 | 오른쪽 화면 드래그 |
| 상호작용 | E | E 버튼 |
| 리어카 잡기/놓기 | F | E 버튼 |
| 장면 넘기기 | Space | 화면 탭 |

진행 상황은 브라우저에 자동 저장되며, 시작 화면의 **이어하기**로 계속할 수 있습니다. **EP.2부터** 바로 시작할 수도 있습니다.

자막은 행동이 일어나는 순간에 맞춰 나오고, 주요 장면(조개껍데기·발자국·전주 저장고 회상·꿈 등)은 컷신으로 보여 줍니다.
