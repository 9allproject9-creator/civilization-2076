# 문명: 멸망 후 50년 뒤 2076년 (팬 게임)

유튜브 채널 「문명」의 영상 **「문명2 EP.1」시작**, **「문명2 EP.2」일상**, **「문명2 EP.3」낚시왕**, **「문명2 EP.4」첫 삽**, **「문명2 EP.5」월동준비** 를 바탕으로 만든 비공식 3D 팬 게임입니다.

▶ **플레이:** https://9allproject9-creator.github.io/civilization-2076/

## 이야기 (EP.1 「시작」)
세상이 멸망한 지 50년, 2076년. 하천 둑길 옆 작은 콘크리트 창고에서 눈을 뜬 주인공은
겨울을 나기 위해 하루를 시작합니다.

1. 침낭에서 일어나 난로 불씨에 장작을 얹고, 작은 스텐 냄비로 물을 끓여 마신다
2. 문가에 흩어진 재첩 껍데기와 작은 발자국 — 쥐의 흔적을 발견한다
3. 리어카 방수포를 들춰 종자 팩을 확인하고, 섬진강 휴게소 주방에서 스텐 밀폐용기를 찾아온다
4. 빈 리어카를 끌고 낡은 마을의 낚시가게에서 합사줄과 낚싯바늘을 구한다
5. 부들·돼지감자·냉이 자리에 나뭇가지를 꽂아 표시하고, 쓰러진 고목에서 하늘소 유충을 얻는다
6. 섬진강교 난간에 낚싯줄 8개를 내려 묶고 집으로 돌아온다 — 그리고 불청객들이 나타난다

## 이야기 (EP.2 「일상」)
쥐가 벽 틈으로 사라진 그날 밤.

1. 스텐 용기를 열어 종자와 식량을 확인하고, 병균이 들어오지 못하게 구멍을 막기로 한다
2. 참나무숲에서 낙엽을 들추다 도토리를 발견하고, 돌멩이와 진흙을 챙긴다
3. 벽 틈새를 돌과 진흙으로 막고, 들통에 냇물을 받아 도토리를 불린다
4. 돼지감자를 난로 안쪽에 넣어 익히고, 상판에서 냉이국을 끓여 식사한다
5. 깜빡 잠든 사이 옛 기억이 스친다 — 일어나 냇가에서 설거지를 하고 페트병 통발을 설치한다

## 이야기 (EP.3 「낚시왕」)
다음 날 새벽.

1. 페트병 통발에 걸린 민물새우를 미끼로 챙겨, 리어카를 끌고 섬진강교로 간다 — 낚싯줄은 모두 빈 바늘
2. 새우 미끼와 돌 무게추를 달아 다시 던지고, 다리 건너 시내로 — 옛날 치킨집 간판 앞에서 잠시 꿈을 꾼다
3. 첫 번째 철물점의 철망은 삭아 부스러지고, 두 번째 철물점 창고에서 스테인리스 롤망과 철수세미, 삽을 찾는다
4. 옛 농가의 화강암 돌절구를 리어카에 싣고 돌아와, 창문에 철망을 대고 외벽 틈새를 막고 집 둘레에 재를 뿌린다
5. 해 질 녘 다시 다리로 — 일곱 번째와 여덟 번째 줄에 팔뚝만 한 농어 두 마리! 마당 모닥불에서 한 마리는 훈제, 한 마리는 소금구이

## 이야기 (EP.4 「첫 삽」)
종자 설명서 카드에서 「토종보리 파종 적기 10월 하순」이라는 문구를 본 다음 날.

1. 폐허가 된 시립 도서관의 무너진 서가에서 곰팡이 슬은 농사 도감을 찾아낸다 — 어젯밤 난롯가의 기억이 스친다
2. 빛이 드는 책상에서 돋보기로 도감을 읽고, 집으로 가는 길에 마을 어귀의 영농자재센터에서 낫·곡괭이·쇠스랑을 챙긴다
3. 숫돌에 낫을 갈아 집 옆 빈터의 억새와 가시덤불을 베고, 곡괭이로 굳은 땅을 부순 뒤 쇠스랑으로 풀뿌리와 돌을 긁어낸다
4. 돌절구에 재첩 껍데기를 빻아 석회 가루를 만들고, 나뭇재와 함께 뿌린 뒤 삽으로 흙을 뒤집어 섞는다
5. 양옆에 물길을 파고 두둑을 만든 다음, 원통형 밀폐 용기에서 꺼낸 토종보리 씨앗을 심는다 — 밤, 창가에서 달빛 내린 밭을 바라본다

## 이야기 (EP.5 「월동준비」)
밭에 씨앗을 심은 다음 날, 본격적인 겨울 채비.

1. 이틀 동안 불려 둔 도토리의 껍질을 벗기고, 마당의 돌절구에 빻아 물에 풀어 녹말물만 따라 모은다
2. 비명을 지르던 리어카 바퀴 축 — 휴게소 한편의 차량 관리 창고에서 오래된 구리스 통을 찾아낸다
3. 바퀴를 분해해 녹을 긁어내고 구리스를 발라 다시 끼운 뒤, 와셔를 끼우고 너트를 조인다
4. 톱과 손도끼를 싣고 뒷산 비탈면에 올라, 말라 죽은 참나무 고사목을 켜고 쪼개 리어카 가득 싣는다
5. 집으로 돌아와 창고 외벽 처마 밑에 장작을 쌓고, 녹말로 도토리묵을 쑤어 먹는다 — 문밖의 밤공기에 하얀 입김이 피어오른다

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 |
| 달리기 | Shift | 달리기 버튼 |
| 시점 | 화면 클릭 후 마우스 (Esc 해제), 휠 줌 | 오른쪽 화면 드래그 |
| 상호작용 | E | E 버튼 |
| 리어카 잡기/놓기 | F | E 버튼 |
| 장면 넘기기 | Space | 화면 탭 |

진행 상황은 브라우저에 자동 저장되며, 시작 화면의 **이어하기**로 계속할 수 있습니다. **EP.2부터**, **EP.3부터**, **EP.4부터**, **EP.5부터** 바로 시작할 수도 있습니다.

자막은 행동이 일어나는 순간에 맞춰 나오고, 자막 속 행동(장작 꺼내기, 손도끼질, 용기에 종자 팩 담기 등)은 실제로 물건이 옮겨지고 도구가 쓰이는 모습으로 보여 주며, 행동 장면에서는 캐릭터가 정해진 자리에 서서 옆에서 잘 보이게 연출되며, 주요 장면(조개껍데기·발자국·전주 저장고 회상·꿈 등)은 컷신으로 보여 줍니다.

## 나레이션
모든 장면 자막(234문장)에 타입캐스트(Typecast) AI 성우 「필재」의 목소리가 입혀져 있고, 1.2배속으로 재생됩니다. 게임 중 **M** 키로 나레이션을 끄거나 켤 수 있습니다. 음성 파일은 `voice/` 폴더에 있습니다.
